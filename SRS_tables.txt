=== TABLE 6 ===
ID | Requirement Description | Priority
FR-MAT-01 | The system shall, given a need record, identify all AVAILABLE resource records of the matching type across all agencies. | Critical
FR-MAT-02 | The system shall rank/select candidate resources using, at minimum, distance to the need location and quantity available. | Critical

=== TABLE 11 ===
Interface | Description
Frontend ↔ Backend API | REST over HTTPS (JSON payloads), built with FastAPI; endpoints include /resources, /needs, /match, /recommendations, /dashboard.
Backend ↔ Database | PostgreSQL with PostGIS extension for geospatial queries (e.g., nearest-available-resource search).
Backend ↔ Optimization Engine | In-process or service call to a Python-based matching module using Google OR-Tools / NumPy / Pandas.
Backend ↔ ML Forecasting Module | Python service using scikit-learn (optionally XGBoost/LightGBM in future) for demand prediction.
Frontend ↔ Map Provider | Leaflet with OpenStreetMap tiles (Mapbox as an optional alternative).
Real-time channel | WebSocket connection (FastAPI native WebSocket support) for live dashboard updates.

=== TABLE 14 ===
Term | Definition
Agency | An organization contributing or requesting resources: NDRF, Army, State Disaster Response Force, NGO, hospital, or local relief organization.
Resource Record | A database entry describing a quantity of a specific resource type held by a specific agency at a specific location, with a status.
Need Record | A database entry describing a requirement for a resource type, quantity, and priority at a specific district/facility.
Unified Resource Registry | The de-duplicated, pooled view of all resource records of a given type within a geographic area, aggregated across contributing agencies.
Deduplication Engine | The system component that computes pooled totals and detects duplicate deployment/procurement.
Matching / Optimization Engine | The system component that, given a need, recommends an allocation of available resources across agencies.
Priority Level | One of Critical / High / Medium / Low, derived from a need's deadline.
Resource Status | One of AVAILABLE, DEPLOYED, IN TRANSIT, RESERVED, DAMAGED, EXPIRED.
Command Centre | The State Authority-level role with full operational visibility and transfer-authorization rights.
RBAC | Role-Based Access Control — restricting data visibility and actions based on a user's assigned role.
