=== TABLE 3 ===
Component | Responsibility
FastAPI REST Service | CRUD for agencies, resources, needs; auth; orchestrates calls to optimization/forecasting workers.
WebSocket Service | Publishes real-time resource/need/allocation state changes to subscribed dashboard clients (FR-RT-01).
Optimization Worker | Runs the OR-Tools-based matching algorithm on demand or on a schedule (FR-MAT-01–07).
Forecasting Worker | Computes time-to-shortage estimates using scikit-learn models (FR-FOR-01–03).
Auth Service | Issues/validates JWTs, enforces RBAC (FR-SEC-01–03, NFR-SEC-01–03).
PostgreSQL + PostGIS | System of record; PostGIS supports nearest-resource geospatial queries.

=== TABLE 11 ===
Method | Endpoint | Description
POST | /auth/login | Authenticate; returns access + refresh JWT.
POST | /auth/refresh | Exchange refresh token for new access token.
POST | /auth/logout | Revoke refresh token.

=== TABLE 12 ===
Method | Endpoint | Description
GET | /resources?district_id=&resource_type=&status= | List resources, filterable; RBAC-scoped (FR-REG, FR-DED-02).
POST | /resources | Create a resource record (FR-REG-01).
PATCH | /resources/{id} | Update quantity/status; owning agency only (FR-REG-03).
GET | /resources/pooled?district_id=&resource_type= | Deduplicated pooled totals by district/type (FR-DED-01).
GET | /resources/nearby?lat=&lng=&resource_type=&radius_km= | PostGIS proximity search.

=== TABLE 13 ===
Method | Endpoint | Description
GET | /needs?district_id=&status=&priority= | List needs, filterable (FR-REG-02).
POST | /needs | Create a need; priority auto-derived (FR-PRI-01).
PATCH | /needs/{id} | Update quantity/deadline/status.

=== TABLE 14 ===
Method | Endpoint | Description
POST | /needs/{id}/match | Trigger the matching engine; returns a PROPOSED allocation (FR-MAT-01–04).
GET | /allocations?status= | List allocations, filterable by status.
POST | /allocations/{id}/authorize | Accept/modify a proposed allocation; sets resources IN_TRANSIT (FR-MAT-05/06).
POST | /allocations/{id}/reject | Reject a proposed allocation; need remains OPEN.

=== TABLE 15 ===
Method | Endpoint | Description
GET | /dashboard/summary | Aggregated surplus/deficit per district/resource type for the map view (FR-MAP-01–03).
GET | /districts/{id}/forecast?resource_type= | Time-to-shortage estimate (FR-FOR-01).
GET | /notifications?unread=true | List alerts for the current user's scope (FR-SEC-04/05).
WS | /ws/dashboard | Authenticated WebSocket channel streaming resource/need/allocation change events (FR-RT-01).
